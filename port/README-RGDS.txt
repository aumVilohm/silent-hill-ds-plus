Silent Hill DS+: Silent Hill (PS1) on two screens for the Anbernic RG DS Plus (ROCKNIXDS)
=========================================================================================

Unofficial, non-commercial fan port. The game is on the top screen, and the game's
original inventory runs live on the bottom screen, so the world keeps going while you
use it. Expect some bugs: this is a first version, and some issues come from the Silent
Hill PC Port it is built on.

No game data is included. Your own disc image goes here:
  /storage/roms/ports/silent-hill-rgds-plus/gamedata/Silent Hill (USA).bin
  /storage/roms/ports/silent-hill-rgds-plus/gamedata/Silent Hill (USA).cue
I tested it with the North American disc SLUS-00707 v1.1 (BIN SHA-1
34278d31d9b9b12b3b5db5e45bcbe548991ecbc7) on ROCKNIXDS 1.6.3-plus (ROCKNIX 20261001).

Saves go to gamedata/save/, logs to logs/ (one folder per run, the last 10 are kept).

Controls (PlayStation layout by position)
  B     action / confirm            A     flashlight / cancel
  X     map on the bottom screen    Y     run
  Select  the pad drives the bottom menu / Harry again
  Start   pause and unpause, also while the pad drives the bottom menu
  Touch   the bottom menu always works by touch
Bottom menu: the original Use, Equip, Unequip, Reload, On/Off and Look.
Map: the original paper map on the bottom screen. The arrows above and below the map
change floors, and the square buttons in the bottom corners close it and zoom. X closes
the map again. A and B act on it only while the pad drives the bottom menu (with the pad
on Harry, A is the flashlight).
Option: the original settings, on the top screen.
Exit: asks "Quit to Ports?" on the bottom screen, and Yes closes the game. You can't get
out from the main menu, so start or load a game first.
